# Katapult Q4 organic, art direction v2

Date: 2026-09-28. Replaces the v1 layout plan after the account lead's review.

## What changed from v1, and why

1. **The Bounce line graphics are retired.** Katapult no longer uses them in current creative (the 2022 guideline is outdated here). That means no Super graphic, no dotted/solid support arcs, no carousel seam arcs, no dotted swipe arrow and no hop paths in the flow diagram. Forward motion now comes from **composition**: stepping tiles, progress squares, cards that stack and fan, and color blocks that change from slide to slide.
2. **Variety comes from interactive mechanics, not more type slides.** No slide is type only. Each one gets its own visual idea, taken from the client's engaging-formats board and rebuilt in Katapult's palette, type and flat shapes: UI input cards, product pickers, bingo and tic-tac-toe grids, a Venn, a triangle, a board-game path, checklists, calendars, icon grids, photos with a floating UI card, editorial type with a collage, and color-blocked panels.

## Rules every slide follows

- **Copy:** only the lines in `copy.md`, each placed once, exactly as written. There are no labels on diagrams, no placeholder text in input fields, no "Swipe", and no letters or numbers the copy doesn't have. Input fields are empty shapes and diagram corners hold icons. The one layout liberty: a subtext made of several sentences can sit as stacked rows (checklist rows), with every character in its original order (post 04 slide 1, post 07).
- **Text never sits on a photo** unless it's inside a solid UI card, and the logo never sits on a photo.
- **Palette:** Pink, Dark Blue, Blue, Light Blue, Orange, Cream, greys, White and the #EAEAE8 surface. Text only uses the approved pairings: Black or Dark Blue on surface/White/Cream/Pink/Orange, and White, Light Blue or Pink on Dark Blue, White on Blue, and Dark Blue on Orange (6.1:1; Orange ground only on 03 s6, with no Pink on it). Light Blue only ever appears as shapes, photo backgrounds or icon discs, never behind text. Cards are flat, and depth comes from a solid offset plate in a palette color, not a shadow or a tint.
- **Icons:** line-icon placeholders (one weight, max two colors). Dark Blue + Pink on White/Cream/surface, White on Pink, Light Blue + Pink on Dark Blue.
- **Photos:** real people, uplifted, on plain solid palette backgrounds, faces uncropped, and nothing crossing a face.
- **Carousels:** several colors may now run inside one carousel, but each post has a color rule stated below, so it reads as one piece. No two consecutive slides share a composition. Opening colors alternate in the feed as they did in v1.

## Mechanic key

| Code | Mechanic (from the board) | Katapult build |
|---|---|---|
| COL | Big editorial type with collage | Display type, overlapping cutouts on color discs/blocks at a shared rotation |
| PICK | Product picker | Grid of rounded tiles holding cutouts, one tile selected (Pink stroke + check disc) |
| UI | Photo with a floating UI card | Full-bleed photo, solid White card carrying the copy, Dark Blue offset plate |
| IN | UI input card | White card with empty field shapes, a send button disc, no placeholder text |
| GRID | Bingo / tic-tac-toe / icon grid | 3x3 or 3x2 cells: icon discs, color blocks, photo cells |
| VENN | Venn, "two aesthetics" | Two overlapping circles, overlap in a third palette color |
| TRI | Triangle, three corners | Solid triangle shape with an icon disc on each corner |
| BOARD | Board game / path | Square tiles on a winding grid path, the current tile filled |
| CHECK | Checklist | Card with checkbox squares, some ticked |
| CAL | Calendar / week grid | Cell grid with no day letters or numbers, some cells filled |
| BLOCK | Color-blocked panels | Two or three flat panels in contrasting palette colors |
| STACK | Stacked / fanned cards | Cards fanned at a shared angle step |
| CTRL | UI controls | Toggles, radio buttons, slider, segmented control, progress segments |

## Repetition check (done)

- No slide is type only, and none is left without a visual.
- Within every carousel, each slide's mechanic differs from both of its neighbours (see the "Consecutive" line under each post).
- Across the run, the most-used mechanics are UI (01 s3, 02 s5, 04 s4, 13 s3, 15 s4, 10) and GRID (04 s3, 05 s4, 06 s2, 13 s2, 15 s2, 09, 11). Each instance differs in cell content and scale.
- Checked after the build: `verify_text.py` 0 problems (both directions, no repeats, no dashes, no Bounce pieces in the page or either DS copy). The layout checker reports 0 issues across 52 canvases.
- No family icon anywhere an icon set stands for what approval looks at (02 s4, 06 s3, 13 s2): familial and marital status are protected bases in US fair-lending rules, so it's swapped for a heart. Which factors may be shown at all is for the client's legal to confirm.
- Post 01 and post 03 cover similar steps, so they use different families: post 01 uses objects (picker, card, progress bar, triangle), while post 03 uses a board game with a track, notification stack, shelf, calendar and doors.
