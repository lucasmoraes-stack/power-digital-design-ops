# Sent emails (raw batch)

Drop folder for Tom's of Maine emails that have already been sent. This is the raw material for the email kit: the kit is built from what the brand sends today, with guideline v4.3 as a complement. Content stays out of git (only this README is versioned).

## What to put here

- **Any format:** HTML exported from the ESP (best, because exact colors, fonts and measurements can be read), `.eml`, PNG/JPG (full screenshot of the email), PDF.
- **It can arrive messy:** subfolders, zips, ESP file names. Organizing happens later, in the inventory.
- **Priority, if everything can't come at once:** the last 12 months first, then the rest.
- HTML saved from a browser with a `_files/` folder next to it: keep the folder with it.

## What comes next

1. Automatic inventory (date, type, thumbnail of each email).
2. Thumbnail board published for the owner to mark what is current and what is legacy.
3. Selection of 20 to 40 representative emails → `01-brand/email-kit/references/`.
