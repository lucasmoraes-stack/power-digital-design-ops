# Reference emails (HTML)

Drop third-party reference emails here (saved from Milled or a browser as `.html`, `.mhtml` or a screenshot) for layout inspiration on the Tom's of Maine emails.

- One file per email. Name it `<brand>-<yyyy-mm-dd>-<topic>.html` when you know the date, e.g. `native-2025-11-28-bfcm.html`.
- Optional: a line in the table below saying what caught your eye, so the designer knows what to borrow.
- Contents of this folder (except this README) are not committed: they are other brands' material, used only as reference. Never copy their copy, colors or assets into a Tom's email.

| File | What to look at |
|---|---|
| Burt's Bees (3) | Photo on top + colour panel with the text (no text on photo); product rows with name, description and link inside one coloured card. Used in 11/28. |
| Each & Every (4) | Round badge over the hero; checkerboard of image / text squares. Used in 11/9 (Tom's starburst seal + 10/13 split cards). |
| Kinship (3) | Framed hero with margins; editorial "Get to know" list with a coloured label, product on the right, hairlines. Used in 11/18. |
