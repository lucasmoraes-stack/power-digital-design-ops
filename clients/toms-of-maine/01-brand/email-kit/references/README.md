# Email references · Tom's of Maine

Emails that calibrate ambition and structure (playbook, stage 2). **Structure references, never visual ones:** another brand's palette, type and exact layout never enter this kit.

## How to add one

1. Save the screenshot (PNG/JPG) or the HTML in this folder. **Never paste the HTML into the chat**: pages saved from email galleries go over 1MB and blow up the prompt. If the saved page comes with a `_files/` folder, the email usually lives in that folder's `iframe.html`.
2. Render it to study: `python email-ops/tools/render.py <file.html> --out <folder>`.
3. Add one line to the table below.
