TEXTURE SHEET (review only) · each strip = the texture as a band background, with the text colors allowed on it. Tiles (tex-*) are 1200x1600, seamless top/bottom: CSS background-size:600px auto; background-repeat:repeat-y, any band height. Gradients (grad-*) stretch to the band: background-size:100% 100%, best for bands 300 to 1200px tall. Outlook desktop: VML type="frame" stretches every texture to the band (grain only, no visible distortion). Worst-case contrast measured on the texture pixels (1st/99th luminance percentile) in the kit README
