# Habit Outdoors · Image library catalogue

The single index of usable photos. `build_image_library.py` reads the table below; each row is one tile on the Image Library page.

- **File**: path relative to `clients/habit-outdoors/01-brand/photos/`.
- **Collection**: `selected` (the curated library, from `_inbox/`), `original` (Habit originals found 2026-09-25), `crop` (provisional crops from the September sent emails, lower resolution: replace with originals).
- **Category**: hunting, fishing, camp, farm, detail, landscape.
- **Calm area**: where live text can sit on the photo (top, bottom, none).
- **Rights**: `released` (cleared for email), `to confirm`, `provisional`.
