Keeping this hub current

Every new artifact for a Power Digital client gets a card here in the same session it is published.

  1. Add an entry to hub/artifacts.json: client, type, status, title, URL, date, a two-line description and its main sections.
  2. Read the new artifact with the Artifact tool, then make its thumbnail from the saved HTML: 
    python hub/build_hub.py thumb <slug> <saved.html>
  3. Build the page: 
    python hub/build_hub.py
  4. Read this hub's live version, then republish hub/power-digital-hub.html to the same URL.
  5. When a board's job ships into a deliverables hub, set the board's status to superseded.
